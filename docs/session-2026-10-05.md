# Dev session — 2026-10-05

**Scope:** XR Animator VMC (`BashhScriptKid/SystemAnimatorOnline-VMC`).
**Baseline:** `6489f90` (stale fork) → **HEAD:** `8405968`.
**Commits this session:** 42 (all on `origin/master`).

A single long session that took the fork from a stale downstream clone to a
branded, native-inference, ONNX-capable app with its own control surface.

---

## What was built

### UI / control surface (Svelte 5 + Vite + Tailwind v4 + Lucide)
- Data-driven panel generated from the live `XRA.config` (15 sections),
  bridged to `XRA.config` + `SA_bridge.backend`.
- **Left quick dock**: category symlinks + tracking/record actions, hover
  labels, busy/state tints; preview toggle removed.
- **Floating category popups**: click a dock icon → that category pops out as a
  non-collapsible, defocus-hiding window that follows the dock's right edge.
- **Blender-style splash**: verbose boot-log column + quick controls; dismisses
  on click-outside/Esc or after 4s without hover; never starts the camera.
- **Movable/resizable mocap window** hosting the real native layers, with a
  content picker (webcam+skeleton / skeleton / webcam / off) and Auto/Always
  visibility (idle = black + "Tracking is off" + buffer flush).
- **Tracking-telemetry styling**, then corrected to pro dark-UI tokens
  (Material/superdesign + Blender HIG): off-pure-black surfaces, off-white text,
  desaturated accents; coherent single accent slider fill; hover-only scales;
  calmer type.

### Backend / inference
- **Native pipeline fixes**: per-frame `video_track.applyConstraints` crash in
  native mode; recorder `nativeXr` ReferenceError; skeleton-canvas visibility
  (pending class) + alignment.
- **Real webcam pipe**: Python MJPEG preview surfaced to the window
  (`/__xra_camera.mjpg`, toggle `/__xra_camera/preview`); on-stage overlay
  retired in favour of the window.
- **Optional ONNX Runtime backend** (`xra_backends/onnx/`): composed
  MediaPipe-architecture model set (OpenCV Zoo pose/person + yakhyo face/hand),
  same wholebody payload, EP-selectable (TensorRT > CUDA > OpenVINO > DirectML >
  CoreML > CPU), registry entry + dispatcher selection.
- **Hand tracking**: wrist-seeded reacquisition + predictive hold
  (`hand_tracker.py`) — adaptive detect cadence, pose-wrist ROI seeding, L/R
  association, One Euro smoothing, hold + blend-in.
- **Backend picker** in the panel: lists backends, downloads on demand,
  switches live, shows active backend/EP, persists the choice.

### Hardening
- **Camera boot sequence**: disable → start → wait for first data → tint;
  timeout → force-stop that kills the capture child
  (`/__xra_camera/force-stop`). Same for the record toggle.

## Key decisions
- **Absorb the Podcasters Edition once, credited** (native Python MediaPipe);
  keep `master` mergeable on upstream v0.35.0.
- **Svelte control surface** over the legacy panel; Tailwind **without
  Preflight** (bundle is injected into the host page).
- **ONNX is opt-in**, MediaPipe default; models download at runtime, not bundled.
- **Hands on weak webcams**: invest in temporal masking (seeding/hold), not a
  new model — a fancier model changes little when the camera is the bottleneck.
- **Name**: brand as *XR Animator VMC*, keep upstream credit; full rename TBD.

## Notable bugs found & fixed
- Vite lib bundle emitted **unwrapped** → top-level Svelte `var $` clobbered
  jQuery → jThree/MMD avatar never loaded. Wrapped in an explicit IIFE.
- `SA_system_emulation` `target_devicePixelRatio` setter called
  `video_track.applyConstraints` unguarded every frame → threw in native mode,
  aborting the update loop before the skeleton draw.
- Two "Guard" group headers collided → `each_key_duplicate` blanked the app.
- Recorder `nativeXr` undefined (recording never started).
- Mocap "Webcam only" still showed the skeleton; mocap window 0-fps readout.

## Known gaps / caveats
- **ONNX blendshapes are derived** (eye/jaw/mouth), not the native 52 ARKit.
- ONNX CPU ≈ MediaPipe here (no GPU/OpenVINO); win is portability.
- Mocap window pixel output verified structurally only (needs a webcam).
- The whole pip is fine on CPU; the **hand tracker lives in the ONNX backend**
  (backend-agnostic, portable to the default path).
- Release mechanics still missing: **package + version tag + install docs**;
  `onnxruntime` is not in `build.sh` deps yet.
- **Naming**: still "XR Animator" in places; upstream name/mark.

## Next steps
